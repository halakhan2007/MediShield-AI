# MediShield AI 🩺

## Project Overview

MediShield AI is a healthcare-focused web application that brings together machine learning-based disease prediction, medical report authenticity analysis, and hospital staff access management in one platform.

The application aims to support healthcare-related data analysis and improve how users interact with predictive tools, medical reports, and sensitive hospital data.

This project was developed collaboratively, with different components built separately and integrated into a unified web application.

## Features

### 1. Disease Prediction
- Provides machine learning-based predictions related to heart, brain, and respiratory diseases.
- Allows users to enter relevant information to receive a prediction based on the available models and datasets.

### 2. Medical Report Authenticity Analysis
- Provides a feature for analyzing medical reports to assess whether a report may be genuine or potentially false.
- Supports report analysis as part of the project's healthcare-focused functionality.

### 3. Hospital Staff Access Management
- Provides access control functionality for managing staff permissions and data access.
- Allows authorized staff to view or manage datasets and staff information.
- Aims to support data privacy by restricting access to selected users.

The application combines frontend components with separately developed prediction and data management features.

## Project Structure and Development

The individual features were developed separately, with components and prediction pages created using Replit. These components were then brought together through the main web application, with the frontend developed using HTML and CSS.

## Project Purpose

MediShield AI explores how machine learning and web development can be combined to create healthcare-related tools, report analysis functionality, and access management features.
